# 立创线圈工具（矩形 / 圆形 PCB 线圈）

## 打开

双击 `打开工具.bat`，或浏览器打开 `index.html`。

## 用法

1. 设板框 **W / H**、线宽、最小间距（默认 0.127）和起点栅格（默认 0.127）
2. 勾选自动连续调匝，或关闭自动后输入固定匝数（支持 0.01 匝精度，最小 1 匝）
3. 在右侧画布 **拖动橙色起点过孔**（只能吸附到最外侧边线）
4. 导出 SVG、DXF 或 EasyEDA 数据；导出层名仅使用“板框层、顶层、底层、多层”

勾选“**双层交错绕制（底面观察同向）**”后，BottomLayer 会相对 TopLayer 径向错开半个节距，并采用与顶层相反的几何螺旋方向：顶层顺时针时底层逆时针，顶层逆时针时底层顺时针。

双层模式下“**起始位置 / 结束位置**”会自动保持在同一侧；单层模式下则保持一内一外。画布上仍可拖动外侧位置。

两个端子使用相邻但不重叠的焊盘。为避免焊盘描边和进线贴得过近，中心距至少为“1.5 × 焊盘直径 + 最小间距”，并向外取整到起点栅格。第二层通过开放区域引到相邻焊盘，避免用外圈导线把另一个端子焊盘包围在内部。

顶层与底层会在末端最近的一对平行匝段提前收尾，并在两者中间放置换层过孔。两侧只用很短的直线接入过孔，不会在结束位置形成“X”形交叉，也不会生成跨越内孔的长连接线。

双端内侧模式会在底层最靠近结束焊盘的匝段提前收尾，再用短引线连接焊盘，避免底层自然终点从内孔另一侧折返回来。

起始位置为内侧时，画布上可拖动的是黄色内侧起始焊盘；外侧换层点不可拖动。黄色焊盘会吸附到内孔范围内的起点栅格，并自动以短引线接入最近匝段。

已去掉中心禁区设置；起点过孔会吸附到最外侧栅格边线，过孔和导线外侧都会离板框至少一个最小间距。自动模式会在可铺范围内以 0.01 匝精度连续匹配目标频率，非整数部分会作为最内侧局部走线实际绘制并导出。默认总等效电容为 68.9 pF，修改后的参数会自动保存在本机浏览器。
